# 10 合同风险规则配置设计（模板 + 个人覆盖）

> Phase 3/4 前置能力：风险规则以“模板”形式管理。**所有人可见**；超管/管理员维护全局模板；普通用户默认使用全局模板，可编辑自己的副本，互不影响，可一键恢复默认。

## 1. 定位与权限

| 角色 | 能做什么 |
| --- | --- |
| 超管 | 查看/维护全局模板；也可维护个人副本 |
| 管理员 | 查看/维护全局模板；也可维护个人副本 |
| 普通用户 | 查看生效规则；修改自己的副本；恢复默认 |

- 规则页面入口对**所有已登录用户**可见；
- 全局模板接口：`risk:rule:manage`（超管+管理员，其余 404 隐藏）；
- 个人副本接口：仅需登录，按当前用户隔离。

## 2. 生效规则语义

- `global`：全局模板中的规则；
- `custom`：当前用户在 `sys_risk_rule_custom` 中的个人副本；
- **生效规则 = 全局模板 + 个人副本（同 code 时个人副本优先）**；
- 修改某条规则时，后端自动把该规则快照写入当前用户副本；其他用户/全局模板不受影响；
- “恢复默认”= 删除当前用户全部个人副本（单条恢复=删除单条副本），恢复后跟随全局模板。

## 3. 数据模型

### 3.1 sys_risk_rule（全局模板，同前）

code/name/category/severity/keywords/description/suggestion/enabled/sort_order + 审计字段。

### 3.2 sys_risk_rule_custom（个人副本）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGSERIAL | PK | |
| user_id | BIGINT | NOT NULL, FK sys_user | 所属用户 |
| code | VARCHAR(64) | NOT NULL | 复制全局规则编码 |
| name/category/severity/keywords/description/suggestion/enabled/sort_order | — | NOT NULL | 个人快照字段 |
| created_at/updated_at | TIMESTAMPTZ | NOT NULL | |
| 唯一约束 | `(user_id, code)` | UQ | 同一用户同一编码仅一条副本 |

索引：`ix_sys_risk_rule_custom_user_id`。

## 4. Markdown 交换格式

保留全局模板导入/导出（超管/管理员）：格式与解析规则同前，`## 规则名` + `- key: value`；个人副本暂不导入/导出。

## 5. API

### 5.1 全局模板（/admin/risk-rules，risk:rule:manage）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/v1/admin/risk-rules` | 全局模板分页 |
| POST/PUT/DELETE | `/api/v1/admin/risk-rules`、`/{id}` | 全局模板 CRUD |
| GET | `/api/v1/admin/risk-rules/export` | 导出全局 Markdown |
| POST | `/api/v1/admin/risk-rules/import` | 导入全局 Markdown |

### 5.2 个人规则（/risk-rules，仅需登录）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/v1/risk-rules` | 当前用户生效规则（global/custom 合并，含 source） |
| PUT | `/api/v1/risk-rules/me/{code}` | 保存/更新个人副本 |
| DELETE | `/api/v1/risk-rules/me/{code}` | 恢复单条默认 |
| POST | `/api/v1/risk-rules/me/restore-default` | 一键恢复默认（删除全部个人副本） |

## 6. 前端页面

- 侧边栏「风险规则」对所有已登录用户可见；
- 页面两个 Tab：
  - **我的规则**（所有人）：显示生效规则，来源标记“默认/自定义”；可编辑、单条恢复、一键恢复默认（确认弹窗）；
  - **全局模板**（超管/管理员）：全局 CRUD + Markdown 导入/导出。

## 7. 安全与审计

- 全局模板写操作（创建/更新/删除/导入）写 `sys_operation_log`，审计 `operator_id`；
- 个人副本写操作不写全局审计（仅本人数据，前端可提示）；
- 导入内容限长 2MB，逐条校验，非法跳过。
