# 10 合同风险规则配置设计

> Phase 3/4 前置能力：先建设“规则配置中心”，为后续合同上传、解析与风险扫描提供可维护的规则底座。本文档定义数据模型、Markdown 交换格式、接口与权限。

## 1. 定位与范围

- 本阶段只做**规则配置管理**（增删改查 + 导入/导出），不实现扫描引擎；
- 规则供后续扫描引擎按 `code + keywords` 匹配合同文本；
- 规则为系统级敏感业务配置，**仅超管可维护**（管理员不可见/不可操作），后续可按权限点放开。

## 2. 数据模型（sys_risk_rule）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGSERIAL | PK | |
| code | VARCHAR(64) | NOT NULL，部分唯一（deleted_at IS NULL） | 规则编码，全局唯一，如 `PAYMENT_ABNORMAL` |
| name | VARCHAR(128) | NOT NULL | 规则名称 |
| category | VARCHAR(32) | NOT NULL | 分类：`payment`/`breach`/`subject`/`ip`/`dispute`/`other` |
| severity | VARCHAR(16) | NOT NULL | 严重级别：`high`/`medium`/`low` |
| keywords | JSONB | NOT NULL，DEFAULT `[]` | 关键词列表（扫描匹配用） |
| description | TEXT | NOT NULL | 风险说明 |
| suggestion | TEXT | NOT NULL | 处置建议 |
| enabled | BOOLEAN | NOT NULL，DEFAULT true | 是否启用 |
| sort_order | INTEGER | NOT NULL，DEFAULT 0 | 排序 |
| created_at/updated_at/deleted_at/created_by/updated_by | — | 审计字段 | 沿用通用混入 |

索引：`ix_sys_risk_rule_category`、`ix_sys_risk_rule_severity`、`ix_sys_risk_rule_enabled`；`code` 部分唯一索引。

## 3. Markdown 交换格式

导出/导入统一为 `.md`，人类可读且可回导；规则按 `code` 幂等 upsert（存在则更新，不存在则创建）。

```markdown
# 合同风险扫描规则

> 导出时间：2026-08-27 12:00:00
> 规则数量：2

## 付款条款异常
- code: PAYMENT_ABNORMAL
- category: payment
- severity: high
- enabled: true
- sort_order: 0
- keywords: 付款, 支付, 预付款, 货款
- description: 检测付款条件与合同约定不一致的风险。
- suggestion: 建议明确付款节点、比例与逾期责任。
```

解析规则：

- 文件以 `#` 开头为标题，`>` 行为元信息（忽略）；
- 每个 `## <名称>` 开始一条规则，后续 `- <key>: <value>` 为字段；
- 必需字段：`code`、`category`、`severity`、`description`、`suggestion`；
- 可选字段：`enabled`（默认 true）、`sort_order`（默认 0）、`keywords`（逗号分隔）；
- 非法规则跳过并计入 `skipped`，不中断整体导入。

## 4. API（均需 `risk:rule:manage`，非超管 404 隐藏）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/v1/admin/risk-rules` | 分页列表；query：page/page_size/keyword/category/severity/enabled |
| POST | `/api/v1/admin/risk-rules` | 新建规则 |
| PUT | `/api/v1/admin/risk-rules/{id}` | 更新规则 |
| DELETE | `/api/v1/admin/risk-rules/{id}` | 软删除规则 |
| GET | `/api/v1/admin/risk-rules/export` | 导出 Markdown（Content-Disposition 附件） |
| POST | `/api/v1/admin/risk-rules/import` | 导入 Markdown；body：`{content}`；返回 `{created,updated,skipped}` |

## 5. 前端页面

- 侧边栏新增「风险规则」，入口仅对拥有 `risk:rule:manage` 权限的用户可见；
- 页面：搜索/分类/级别/启用状态筛选 + 新建、导入、导出；
- 编辑弹窗：编码、名称、分类、级别、关键词（逗号分隔）、风险说明、处置建议、启用、排序；
- 导入弹窗：粘贴 Markdown 或选择 `.md` 文件读取到文本框后提交。

## 6. 安全与审计

- 规则写入（新建/更新/删除/导入）写入 `sys_operation_log`；
- 导入内容限制长度（≤ 2MB），按规则逐条校验，避免原子失败；
- 导出不包含任何敏感配置。
