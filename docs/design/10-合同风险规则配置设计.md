# 10 合同风险规则配置设计（模板 + 个人覆盖）

> Phase 3/4 前置能力：风险规则以“模板”形式管理。**所有人可见**；超管/管理员维护全局模板；普通用户默认使用全局模板，可编辑自己的副本，互不影响，可一键恢复默认。

## 1. 定位与权限

| 角色 | 能做什么 |
| --- | --- |
| 超管 | 查看/维护全局模板；也可维护个人副本 |
| 管理员 | 查看/维护全局模板；也可维护个人副本 |
| 普通用户 | 查看生效规则；修改自己的副本；恢复默认 |

- 规则页面入口对**所有已登录用户**可见；
- 全局模板接口：`risk:rule:manage`（超管+管理员，其余 404 隐藏）；
- 个人副本接口：仅需登录，按当前用户隔离。

## 2. 生效规则语义

- `global`：全局模板中的规则；
- `custom`：当前用户在 `sys_risk_rule_custom` 中的个人副本；
- **生效规则 = 全局模板 + 个人副本（同 code 时个人副本优先）**；
- 修改某条规则时，后端自动把该规则快照写入当前用户副本；其他用户/全局模板不受影响；
- “恢复默认”= 删除当前用户全部个人副本（单条恢复=删除单条副本），恢复后跟随全局模板。

## 3. 数据模型

### 3.1 sys_risk_rule（全局模板）

字段：`id/code/rule_text/name/category/severity/keywords/description/suggestion/enabled/sort_order` + 审计字段。

**一句话规则（核心，开放化）**：
- `rule_text`（TEXT，必填）：规则的自然语言描述，可以只是**一句话**，例如「付款不得约定一次性全额付款且无质保金」「必须明确知识产权归属」。这是 AI 理解规则、逐条校验合同的唯一依据；
- `code`：自动生成（`RULE_<8位随机>`），用户可不填；数据库仍唯一；
- `name`：可空，缺省截取 `rule_text` 前 30 字符；
- `category`：可空，开放维度（任意 ≤32 字符）。用户可不填，AI 校验时自动归类；
- **内置默认维度（14 个，可任意增删）**：project 项目管理 / technology 技术风险 / contract 合同条款 / general 通用风险 / subject 主体与签署 / payment 付款与结算 / delivery 交付与验收 / breach 违约责任 / ip 知识产权 / confidential 保密与数据安全 / dispute 争议解决 / tax 税务与发票 / warranty 质保与售后 / compliance 合规审查；
- `severity`：可空，缺省 `medium`；AI 校验发现违反时给出实际严重度；
- `keywords`：可空，仅作为 AI 未配置时的关键词降级预筛，不再强制；
- `description`/`suggestion`：可空，由 AI 校验动态生成，历史快照字段保留；
- `enabled`/`sort_order`：保留。

> 人只需要写一句「我想防止什么」，其余交给 AI 理解；字段只是可选的辅助信息。

**扫描语义变更**：扫描时**每条规则 = 一个独立 AI 校验任务**，并发执行（详见《11》2.4）。

- 内置默认规则库：**52 条**（见 backend/app/domain/default_risk_rules.py），每条含 rule_text + 完整字段；bootstrap 按 code 增量补种——缺哪条补哪条，不覆盖用户已修改规则。

### 3.2 sys_risk_rule_custom（个人副本）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGSERIAL | PK | |
| user_id | BIGINT | NOT NULL, FK sys_user | 所属用户 |
| code | VARCHAR(64) | NOT NULL | 复制全局规则编码 |
| name/category/severity/keywords/description/suggestion/enabled/sort_order | — | NOT NULL | 个人快照字段 |
| created_at/updated_at | TIMESTAMPTZ | NOT NULL | |
| 唯一约束 | `(user_id, code)` | UQ | 同一用户同一编码仅一条副本 |

索引：`ix_sys_risk_rule_custom_user_id`。

## 4. Markdown 交换格式（开放维度 + 一句话规则）

全局模板导入/导出（超管/管理员）支持两种格式，均以「人可读」为原则：

**格式 A（推荐，一句话规则）**：

```markdown
# 合同风险扫描规则          <!-- 文档标题 -->

# 财务风险                  <!-- 一级标题 = 维度（分组） -->
- 付款不得约定一次性全额付款且无质保金
- 必须明确逾期付款的违约责任

# 知识产权
- 必须明确知识产权归属
```

- `# 一级标题` = 维度；其下每行 `- 一句话规则` 即一条规则；
- code 自动生成、severity 缺省 medium、keywords 为空（AI 校验时理解规则）；
- 与格式 B 可混用（某行含 `key: value` 时按字段解析）。

**格式 B（兼容旧格式，完整字段）**：

```markdown
# 财务风险
## 付款条款异常
- code: FIN_PAY
- severity: high
- keywords: 付款, 预付
- rule_text: 付款不得一次性全额支付且无质保金
```

- 导出统一输出格式 A（一句话规则，维度分组），易读易改；
- 全局模板页支持直接编辑 Markdown，**保存即校验**，存在错误返回 `20002` 且不写入数据库；个人副本暂不导入/导出。

## 5. API

### 5.1 全局模板（/admin/risk-rules，risk:rule:manage）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/v1/admin/risk-rules` | 全局模板分页 |
| POST/PUT/DELETE | `/api/v1/admin/risk-rules`、`/{id}` | 全局模板 CRUD |
| GET | `/api/v1/admin/risk-rules/export` | 导出全局 Markdown |
| POST | `/api/v1/admin/risk-rules/import` | 导入全局 Markdown |

### 5.2 个人规则（/risk-rules，仅需登录）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/v1/risk-rules` | 当前用户生效规则（global/custom 合并，含 source） |
| PUT | `/api/v1/risk-rules/me/{rule_id}` | 保存/更新个人副本 |
| DELETE | `/api/v1/risk-rules/me/{rule_id}` | 恢复单条默认 |
| POST | `/api/v1/risk-rules/me/restore-default` | 一键恢复默认（删除全部个人副本） |

## 6. 前端页面

- 侧边栏「风险规则」对所有已登录用户可见；
- 页面两个 Tab：
  - **我的规则**（所有人）：显示生效规则，来源标记“默认/自定义”；可编辑、单条恢复、一键恢复默认（确认弹窗）；
  - **全局模板**（超管/管理员）：全局 CRUD + Markdown 导入/导出。

## 7. 安全与审计

- 全局模板写操作（创建/更新/删除/导入）写 `sys_operation_log`，审计 `operator_id`；
- 个人副本写操作不写全局审计（仅本人数据，前端可提示）；
- 导入内容限长 2MB；严格校验：任一规则非法则整批拒绝并返回具体错误（`20002`），不修改数据库。
