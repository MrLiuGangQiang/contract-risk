# 11 合同风险识别核心功能设计

> Phase 3/4 核心：上传合同 → 提取文本 → 规则匹配 → 输出风险结果。本阶段为单机同步扫描（文件较小、规则为关键词匹配），任务队列/对象存储作为后续增强项。

## 1. 范围与原则

- 支持格式：`.txt`、`.pdf`、`.docx`（旧 `.doc` 不支持，前端提示）；
- 单文件上限：20MB；解析文本上限：5MB；
- 扫描规则：使用**当前用户生效规则**（全局模板 + 个人副本，个人优先）；
- 扫描周期：同步返回，文件解析 + 关键词匹配；
- 数据隔离：用户只能查看/删除自己的合同和风险结果；
- 权限：全部登录用户可上传、扫描、查看自己的合同；不开放跨用户查看。

## 2. 识别引擎（规则 + AI）

### 2.1 规则关键词匹配（基础层）

1. 提取纯文本并归一化；对每条启用规则的关键词逐个查找（忽略大小写）；
2. 命中生成 `source=rule` 的风险结果（规则快照 + 命中关键词 + 上下文 snippet）；
3. 结果按 severity 与 sort_order 排序。

### 2.2 AI 增强识别（可配置，降级安全）

- 接入 **OpenAI 兼容 Chat Completions API**，由超管在「AI 配置」页面维护（存储于 `sys_config(config_key='ai')`，`api_key` 加密、读取脱敏、支持连通性测试），默认关闭：
  - `AI_ENABLED`、`AI_API_BASE`、`AI_API_KEY`、`AI_MODEL`、`AI_TIMEOUT_SECONDS`、`AI_CONTEXT_CHARS`、`AI_MAX_FINDINGS`；
- 发送内容：合同文本（截断 `AI_CONTEXT_CHARS`）+ 当前启用规则摘要（编码/名称/维度/级别/说明/建议），要求返回结构化 JSON；
- 返回字段：`rule_code/rule_name/category/severity/matched_keywords/snippet/description/suggestion`；
  - `rule_code` 命中已有规则编码时，作为该规则 AI 增强（`source=ai`，与规则命中同码则去重）；
  - 未命中已有规则时生成新风险（自动编码 `AI_FINDING_<n>`）；
- **降级**：AI 未配置/超时/异常时自动回退纯规则匹配，扫描绝不因 AI 失败而失败；
- 安全：发送给 AI 的合同文本可能含敏感信息，生产应使用企业私有化模型并在配置页/安全评审确认；当前通过环境变量控制。

### 2.3 结果合并

1. 规则命中 + AI 发现合并；
2. 同 `rule_code` 去重（保留规则命中，AI 仅补充新发现）；
3. 统一按 severity 排序后写入 `sys_contract_risk`，`risk_source` 标记 `rule` / `ai`；
4. 重新扫描：事务内原子替换。

## 4. 文件解析

- txt：优先 UTF-8，失败回退 GB18030；
- pdf：`pypdf` 逐页 `extract_text()`；
- docx：`python-docx` 提取段落与表格文本；
- 解析失败返回业务错误，不入库；
- 文件保存目录：`UPLOAD_DIR`（默认 `backend/data/contracts`），文件名 = `uuid.原扩展名`。

## 5. API（均需登录；仅本人数据）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/v1/contracts/upload` | 上传合同（multipart `file`），创建异步任务并返回 `{job_id}` |
| GET | `/api/v1/contracts/jobs/{job_id}` | 查询任务进度（Redis 存储，前端轮询） |
| GET | `/api/v1/contracts` | 分页列表（page/page_size/keyword/severity） |
| GET | `/api/v1/contracts/{id}` | 合同详情 + 风险列表 |
| POST | `/api/v1/contracts/{id}/rescan` | 重新扫描（异步任务，返回 `{job_id}`） |
| DELETE | `/api/v1/contracts/{id}` | 软删除合同（删除风险结果） |

- 上传失败/文件非法：`20002` 参数错误；
- 非本人合同：返回 404（隐藏）；
- 写操作（上传/重扫/删除）写 `sys_operation_log`。

## 6. 前端页面

- 侧边栏新增「合同识别」（所有登录用户）；
- 页面：
  - 上传区（拖拽/选择文件，支持 txt/pdf/docx，≤20MB）；
  - 合同列表：文件名、字符数、风险总数、高/中/低统计、时间、操作（查看/重扫/删除）；
  - 详情：按维度分组展示风险卡片（级别、命中关键词、上下文、建议），支持重新扫描；
- 首页「合同上传（即将上线）」卡片改为可用入口。

## 7. 安全与运维

- 上传文件仅解析文本，不执行内容，防路径穿越（uuid 文件名）；
- 原始文件保存在 `UPLOAD_DIR`，生产应替换为对象存储并定期清理；
- 扫描为**后台异步任务**：任务状态存 Redis（`job:contract_scan:{job_id}`，TTL 10min），前端轮询展示阶段进度：读取文件 → 提取文本 → 规则匹配 → AI 分析 → 生成结果；失败返回明确阶段错误。
